# FTC Scout 🚀

**FTC Scout** is a web application designed to help teams in the **FIRST Tech Challenge (FTC)** keep track of their competition data, analyze robot performance, and improve their strategies. It allows users to record match scores, robot data, and more, and sync everything across devices for easy access and sharing.

This app simplifies the scouting process and makes organizing competition data a breeze. 📝🤖

## Features 🌟

- **Match Scouting**: Record scores, strategies, and other key data for each match.
- **Robot Performance Logging**: Track robot performance in different stages of the competition.
- **Data Sync**: Automatically sync your data across multiple devices with a single user account.
- **Easy Deletion**: Long press on any item to delete it, with a confirmation pop-up to avoid accidental deletions. 🗑️
- **Excel Export**: Export all your data into an Excel file for analysis or sharing. 📊
- **Cloud Sync**: Each team only needs to register one account, and all the data is synchronized across multiple devices. ☁️
